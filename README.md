# Kotys Carpet

Україномовний магазин килимів: каталог із варіантами розміру, кошик та заявка на замовлення. Версія для телефона і комп’ютера.

## Поточний стан

Каталог `data/catalog.json` порожній: власник обрав свої товари, але фотографії, розміри та ціни ще не надані. У шапці використано декоративну ілюстрацію інтер’єру; вона не представляє товар у продажу.

Після заповнення каталогу покупець обирає розмір, додає товар у кошик та залишає ім’я й телефон. Сервер рахує суму за каталогом, зберігає заявку в D1 і повертає номер. Повторне відправлення з тим самим ідентифікатором не створює дубль. Контакти не публікуються; перегляд заявок доступний власнику через інструменти бази сайту в ChatGPT. Сповіщення продавцю та онлайн-оплата ще не підключені.

## Додавання товарів

1. Помістіть фото в `public/images/products/` з назвами латиницею.
2. Заповніть `data/catalog.json` масивом записів такого формату.
3. Перевірте типи, тести та збірку, потім опублікуйте оновлення.

```json
{
  "id": "unique-product-id",
  "name": "Назва вашого килима",
  "description": "Опис вашого товару",
  "material": "Фактичний склад",
  "image": "/images/products/your-photo.webp",
  "imageAlt": "Опис килима на фотографії",
  "variants": [
    {
      "id": "unique-size-id",
      "size": "160 × 230 см",
      "priceKopiykas": 250000,
      "available": true
    }
  ]
}
```

Цей запис є прикладом структури та не входить у каталог. Ціни задаються цілими копійками: 250000 = 2500 грн. Ідентифікатори товарів і розмірів мають бути унікальними; варіанти без наявності не можна замовити.

## Локальна розробка

Node.js 22.13+ та pnpm.

```sh
pnpm install
pnpm dev
pnpm test
pnpm exec tsc --noEmit
pnpm build
```

Стек: React, TypeScript, Vinext, Cloudflare Workers та D1. Сторінка — `app/storefront.tsx`, стилі — `app/globals.css`, форма — `app/api/orders/route.ts`. Залежності й lockfile збережено.

## Заявки

D1-таблиця `order_requests` зберігає контакти, номер заявки, склад кошика, суму в копійках і час. Приймання заявки не списує оплату. Наявність, доставку й оплату продавець погоджує з покупцем.

Схема — `db/schema.ts`. Міграції — `drizzle/`. Для нового локального середовища після збірки застосуйте міграцію до локального D1:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_*.sql
```

Для робочого сайту міграції застосовує платформа Sites. Секретів і контактів покупців у репозиторії немає.
